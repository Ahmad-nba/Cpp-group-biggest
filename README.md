# Cpp-group-biggest assignment implementation. 
### The objective
Implement the mathematical functions of pow(), log10(), naturallog(), exponential(), and modulow(). 
- We implement this on a dataframe to immitate the behavior of libraries like pandas when working with data processing. 

### The implementation
Each group memeber wrote a function that loops over a sample dataframe which is modeled using a vector. The function loops over each value in the dataframe and runs the function on each value in every row of the dataframe.
